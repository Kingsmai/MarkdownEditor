# 墨记 · INKNOTE

一个接近 Typora 单栏写作体验的 Markdown 编辑器 MVP。React + Vite + Tiptap，没有后端。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

打开终端显示的地址，默认是 http://localhost:5173。Windows PowerShell 若禁止 npm 脚本，可使用 `npm.cmd run dev`。

```bash
npm test
npm run build
npm run preview
```

`dist/` 是可部署到任何静态托管服务的生产版本。PWA 的离线缓存仅在生产构建生效；正式部署需要 HTTPS，localhost 可用于本地验证。手机可访问同一局域网内终端显示的 Network 地址来预览界面；普通局域网 HTTP 地址无法注册离线服务。

## 已实现

- 单栏所见即所得编辑，以及 Markdown 输入快捷规则。
- 标题、加粗、斜体、删除线、列表、任务清单、引用、链接、图片、代码块和基础表格。
- 源码模式；文件导入先保留原文，不进行格式转换。
- 多文档、新建、重命名、删除确认、全文搜索和收藏。
- 当前浏览器本地自动保存：500 ms 防抖；页面离开或进入后台时立即保存。
- 自动大纲及跳转、中英文混合字数估算、阅读时间。
- Markdown 文件导入、拖放和下载导出；富文本模式支持浏览器打印 / 保存 PDF。
- 浅色 / 深色主题、专注模式、桌面 / 平板 / 手机布局。
- 生产版本 PWA：离线写作、浏览器支持时安装到桌面。

## 当前流程 → MVP 流程

空项目 → React 界面 → Tiptap 编辑 / 源码 textarea → App 文档状态 → localStorage 自动保存 / .md 导出。

编辑时，Markdown 原文保存在 App 的文档数组中；富文本由 Tiptap 根据 Markdown 解析生成。富文本修改再序列化回 Markdown，源码修改直接更新字符串。切换文档时重新创建编辑器，避免上一篇文档的撤销操作影响下一篇。

| `src/main.jsx`、`index.html` | React 启动入口、页面元信息 | 启动配置、网页标题和语言 |

## 数据和限制

- 文档保存在当前浏览器 / 当前站点的 localStorage，不会跨浏览器或跨设备同步。清理浏览器数据会删除文档，请定期导出 .md。
- 从开发地址切换到生产地址（不同端口也算不同站点），文档不会自动迁移。先导出，再导入。
- 富文本编辑会规范化 Markdown 的空格和列表写法。源码模式保留字符串。包含 YAML、公式、脚注、原始 HTML 或扩展块的文档会限制为源码编辑，避免丢失不支持的内容。
- 当前不是 Typora 的逐字符源码显隐实现；采用成熟编辑器提供单栏即时格式化。代码高亮、数学公式、Mermaid、文件夹管理和原生桌面安装包尚未加入。
- 打开文件会创建浏览器内文档副本；导出下载 .md，不直接覆盖原磁盘文件。单文件导入上限 2 MB。
- 所有文档共享浏览器存储配额，配额不足时会提示导出备份。启动读取损坏数据时阻止自动覆盖原始数据。
- 切换源码 / 编辑模式或切换文档会重置编辑器撤销历史，内容仍会保留。
- 外链图片和 Google Fonts 需要网络；离线时文字编辑可用，字体使用本地回退。
- 字数是中文字符 + 其他语言词组的估算值，阅读时间按每分钟 300 字估算。
- 未实现多标签页同时编辑时的冲突合并；请在一个标签页内维护同一工作空间。

## 验证

`npm test` 的 11 项测试全部通过，覆盖本地恢复和关键 Markdown / URL 边界。生产构建已通过，生成静态站点和预缓存服务。

离线实测：停止本项目的生产预览服务器后，刷新仍能打开编辑器，并能切换文档和渲染 Markdown。验证后已恢复服务器。桌面与手机截图保存在 docs/。

浏览器验收覆盖：源码与富文本切换、任务勾选回写 Markdown、表格 / 代码块显示、刷新恢复、搜索、重命名、快捷格式、导出、深色与专注模式、375px 手机布局。

编辑核心使用官方 [Tiptap Markdown 扩展](https://tiptap.dev/docs/editor/markdown/getting-started/basic-usage)。依赖版本由 package-lock.json 固定。
